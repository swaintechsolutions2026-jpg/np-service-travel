# NP Service – Tour & Travels

Premium, mobile-first website for NP Service – Tour & Travels (Baripada, Odisha · "Service You Trust Since 1992"): tour discovery, confirmed departures, and WhatsApp/phone booking enquiries.

**Stack:** TanStack Start (React 19, TypeScript), Tailwind CSS 4, shadcn/ui, Netlify (Image CDN; Database, Identity and Blobs planned).

**Run locally:** `pnpm install` then `netlify dev` (or `npm run dev`).

**Roadmap:** see [PLAN.md](PLAN.md) — admin dashboard, database-backed content, saved enquiries, staff auth, Odia content, sitemap.
